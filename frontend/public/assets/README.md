# 에셋 교체 안내

여기 있는 파일들은 **Figma 원본이 도착하기 전까지 쓰는 임시 SVG**입니다.
아래 **파일명을 그대로 유지한 채 덮어쓰면** 코드 수정 없이 실제 디자인 에셋으로 교체됩니다.
(PNG로 내보내는 경우 `.svg` 대신 `.png`로 저장한 뒤, `src/utils/heartGrade.js`의
`asset` 경로와 이 표의 사용처만 확장자를 바꿔주세요.)

| 파일명 | 사용처 | 권장 크기 | 배경 |
|---|---|---|---|
| `heart-good.svg` | 4.0~5.0 하트 (등급 안내, 최근 방문 목록, 지도 핀) | 48×48 | 투명 |
| `heart-normal.svg` | 2.0~3.9 하트 (반쪽 채운 하트) | 48×48 | 투명 |
| `heart-bad.svg` | 0~1.9 하트 (깨진 하트 외곽선) | 48×48 | 투명 |
| `raccoon-lovey.svg` | 우하단 마스코트 '러비' | 132×120 | 투명 |
| `couple-avatar.svg` | '우리의 러브맵' 카드 커플 일러스트 | 120×120 | 투명 |
| `pink-tape.svg` | 카드 모서리 테이프 장식 | 120×40 | 투명 |
| `photo-placeholder.svg` | 사진이 없을 때의 자리표시 | 100×100 | 불투명 가능 |
| `paper-texture.svg` | 종이 질감 (반복 타일) | 180×180 | 반투명 |

## 주의

- 하트 3종은 **크기와 시각 무게가 서로 같아야** 합니다. 지도 핀과 목록에서 나란히 놓입니다.
- 마스코트는 콘텐츠를 가리지 않도록 **여백 없이 타이트하게** 잘라 주세요. 배치는 CSS가 담당합니다.
- 텍스트(장소명·점수)는 절대 이미지에 포함하지 마세요. 전부 HTML로 렌더링합니다.
